IN DEVELOPMENT

RokrOS Linux

A custom Linux operating system currently being developed as part of the DaryTech project.

The goal is to create a personalized Linux experience, with a graphical interface and command-line tools, while exploring compatibility with older computers.

⚙️ Development status

Active experimentation and system customization.

Features and plans may change during development.

💿 Compatibility goals

Exploring support for x86_64 computers and older hardware.

Compatibility is not guaranteed at this stage.

🔒 Public availability

RokrOS Linux has not been released to the public.

There is currently no public release to download.

Development roadmap

1. Base system
Experimenting with the Linux base and build environment.
2. User experience
Working toward a custom graphical interface and CLI tools.
3. Hardware testing
Testing booting and compatibility on target systems.
4. Future public release
No public release is available yet. Future availability will depend on development progress.
